# M2 — Core loop (weeks 6–9)

Goal: the loop people use every day (open the app, browse, tap, watch), ending with the first App Review probe.

## Tasks

- [x] **Feed, search and channel screens** on `LazyVStack`/`LazyVGrid`:
  - Strings pre-formatted in the store layer (`RowFormatter`).
  - Shared `Equatable` `VideoCell` in DesignSystem.
  - Channel grid columns follow the available width.
- [x] **Image pipeline** (`DesignSystem/ImagePipeline`):
  - ImageIO decodes and downsamples to the exact cell pixel size, off the main thread.
  - Memory cache, plus a disk cache of the *downsampled* bytes.
  - Duplicate requests coalesce, and YT Zero's image cache gets the Bearer token.
  - Prefetch runs 6 rows ahead in the scroll direction.
- [x] `PlaybackSession` owned outside the view hierarchy, with attachable render surfaces (M0).
- [x] `PlaybackEngine` protocol and `MPVEngine` (M0).
- [x] **Codec policy and format selection:**
  - Codec support comes from `VTIsHardwareDecodeSupported` (`DecodeCapabilities`).
  - Throughput-based selection (`FormatSelector`), fed by mpv's measured download speed.
  - `PlaybackPlanner` applies all of it to a watch page.
- [x] **mpv cache and demuxer tuned for instant seeking:**
  - 150 MiB ahead, with 50 MiB kept behind the playhead and a seekable cache.
  - Playback starts before the cache fills (no initial pause).
  - Quick resume after a stall (0.5 s), and a 512 KiB stream buffer.
- [x] **Watch page with a zoom transition from the thumbnail** (`matchedTransitionSource` → `.navigationTransition(.zoom)`). The channel opens inside the Watch sheet (typed `WatchRoute`).
- [x] **Mini-player with interactive dismissal.** Swiping the Watch sheet down keeps playback going in the tab bar's bottom accessory (iOS 26.1+); tapping it reopens the Watch screen.
- [x] **Resume positions** saved every 5 s and on pause, end or switch (M0 fixes). Near the end counts as finished. Mirrored to a linked YT Zero account.
- [x] **Warm-up for tap-to-play:**
  - Manifest prefetch on touch-down and for the top 3 feed rows, through a manifest cache honouring stream expiry.
  - mpv core pre-warmed after the first frame.
  - Instance connections opened by a health check after the first frame.
- [ ] **App Review probe build with the demo instance in the review notes.** Owner action: requires the Apple developer account. Review notes are drafted in `docs/app-review.md`.

Also added:

- **Settings:** hide Shorts (on by default) and YouTube's "Up next" suggestions (shown by default).
- **Expired streams** recover automatically at the same position.

**Done when:** tap-to-first-frame is under 300 ms warm, the scroll hitch ratio is under 5 ms/s, cold launch to feed is under 400 ms, and the App Review probe outcome is known.

- **Gates:** measured by `PerformanceGateTests`. The scroll gate now scrolls the real feed screen with 1,000 cached videos. The authoritative numbers must come from a ProMotion device (owner); simulator numbers are a trend only.
- **App Review:** waiting on the owner.

## Verified (simulator, owner's Piped instance)

`FeedFlowUITests` and `BrowseFlowUITests`:

- Adding an instance through the UI fills the feed (refresh plus backfill).
- Tapping a video plays it.
- Search returns results.
- Watch → channel shows the correct subscription state.
- Dismissing shows the mini-player, and tapping it reopens a still-playing Watch screen.
