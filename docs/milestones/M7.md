# M7 — tvOS (weeks 21–24)

Goal: the shared packages on the Apple TV 4K, with a TV-first interface rather than a scaled-up phone UI, and the phone and TV sharing one library.

## Tasks

- [x] **tvOS app target reusing `Core`, `Library` and `Playback`** (`App/tvOS`, its own XcodeGen project):
  - Every package builds for tvOS; the few iOS-only APIs are guarded.
  - **Composition root:** the app shares `App/Shared` (`AppEnvironment`, settings, licences) with iOS (ADR 0004).
  - **Licences:** the bundle passes the LGPL gate and ships the open-source notices.
- [x] **Focus-driven home, feed, search and channel screens with Liquid Glass:**
  - **Home:** Continue Watching and Queue shelves above the subscriptions grid.
  - **Search:** the system search keyboard.
  - **Channel:** pages with Subscribe.
  - **Settings:** instances, YT Zero pairing (its QR code suits the TV), preferences and licences.
  - **Focus:** cards use the system `.card` focus lift. The transport bar and skip notice use glass.
  - **Rendering:** screens render from the database first, through the shared feature models.
- [x] **Top Shelf extension with subscriptions and continue watching:**
  - The app writes a JSON snapshot into the App Group, which the extension reads.
  - Items deep-link into the player.
  - The link format is unit-tested (`HomeSnapshotTests`).
- [x] **Siri Remote:**
  - Select or Play/Pause toggles playback.
  - Left/right skip back 10 s and forward 10 s.
  - Down opens chapters as a focusable shelf.
  - Menu closes the chapters, then the player.
  - Right after a SponsorBlock skip, left undoes it.
  - Controls fade after 4 s.
  - **Not yet:** swipe scrubbing on the touch surface needs a UIKit indirect-pan recogniser, which has to be tuned on a real remote.
- [ ] **mpv on tvOS with AV1 hardware decode; validate 4K60 HDR.** mpv (MoltenVK/Metal) builds and links for tvOS. The codec policy already queries AV1 hardware decode at runtime. Owner check on the Apple TV:
  1. Play an AV1 4K60 video.
  2. Confirm the decoder logged as `videotoolbox`.
  3. Check that HDR is preserved. HDR is still off (`allowHDR: false`), so enabling it is part of this check.
- [ ] **Tune the VP9 software-decode resolution cap on the A19.** This needs the device: measure dropped frames at 1440p and 2160p VP9, then set the cap in `DecodeCapabilities`.
- [x] **Subscription and history sync with the phone** (ADR 0004):
  - `CKSyncEngine` in the private database: last writer wins on `modifiedAt`, tombstones for deletes, change tags kept.
  - A linked YT Zero takes over, as ADR 0002 decided.
  - **Tests:** `SyncTests` cover pending rows, both conflict directions, account changes and record mapping.
  - **Fixed on the way:**
    - Saving a resume position used to drop the stored CloudKit change tag, which would have turned every upload into a conflict.
    - Re-subscribing to an unchanged channel counted as an edit.
  - **Off until set up:** sync is off until the owner configures the iCloud container (see the ADR).
- [ ] **Performance gates re-run on tvOS:** launch, focus movement and tap-to-play. The same signposts (`launch.firstFeedFrame`, `playback.tapToFirstFrame`) are in the TV app; they're measured on the device.

## Verification

- **Builds:** iOS app and tvOS app (simulator). The tvOS app is built in CI with its licence gate.
- **Unit tests:** Library 35 (sync), SpectoTests 6 (CarPlay, Top Shelf links), plus the existing package suites.
- **Not run here:** no tvOS simulator runtime is installed, so the TV UI hasn't been exercised. Installing the runtime (Xcode → Settings → Components) allows that.
- **Owner checks on the Apple TV:**
  1. Focus moves smoothly across the home grid and shelves.
  2. The remote controls above work as described.
  3. Top Shelf shows Continue Watching after watching something; selecting it opens the video.
  4. With sync configured, a subscription added on the iPhone appears on the TV, and a resume position carries over.

**Done when:** 4K AV1 HDR plays smoothly, navigation feels instant with the remote, and history matches the phone. These are device checks for the owner; everything they depend on is built.
