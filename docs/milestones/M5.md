# M5 — Beta hardening (weeks 16–17)

Goal: turn the iOS build into a public beta and settle the distribution question.

## Tasks

- [x] **Privacy manifest** (`App/iOS/Resources/PrivacyInfo.xcprivacy`):
  - No tracking, no tracking domains, no collected data types.
  - Required-reason APIs: UserDefaults (CA92.1), file timestamps (C617.1), elapsed time (35F9.1). Declarations match what the app really uses; disk space is added with M6 downloads.
  - **App Store privacy details:** "Data Not Collected".
- [x] **MetricKit collection** (`DiagnosticsCollector`): metric payloads (launch, hitches, hangs) are stored on the device, the last 30 kept.
- [x] **Privacy-respecting crash reporting:**
  - MetricKit diagnostic payloads (crashes, hangs) go to the same local store.
  - **Settings → Diagnostics** lists them with summaries; each can be shared deliberately, and all can be deleted.
  - No SDK, nothing sent automatically.
- [x] **Onboarding copy explaining bring-your-own-instance.**
  - **Empty feed:** "Bring your own server" explains the model.
  - **Navigation:** it goes straight to Instances, where URL detection, YT Zero pairing and subscription import live.
  - **Settings → About:** repeats that the app has no servers and collects no data.
- [x] **Final review notes:** `docs/app-review.md`, with the demo instance and test steps. Fill in the URL and contact details at submission; never commit them.
- [x] **Performance gates as a CI release gate:**
  - `scripts/perf-gate.sh` checks launch, tap-to-first-frame and hitch ratio against the CLAUDE.md targets.
  - CI reports them on every run.
  - `.github/workflows/release.yml` enforces them on version tags, on a self-hosted Mac with a ProMotion iPhone attached.
- [ ] **Public TestFlight group.** Owner action: needs the developer account and a real bundle ID (`docs/distribution.md`).
- [x] **Fallback plan if App Review rejects** (`docs/distribution.md`), in order:
  1. Clarify and resubmit.
  2. TestFlight internal testers.
  3. EU alternative marketplace (notarisation).
  4. Direct install on the owner's devices.

  Offline downloads stay out of App Store and TestFlight builds (guideline 5.2.3).
- [x] **Open-source notices** (Settings → About), required by the LGPL: `docs/licenses.md` is bundled into the app, with the LGPL source offer.

**Done when:** public TestFlight is live and the App Review outcome is known. Both are owner actions; everything they depend on is ready.
