# M6 — CarPlay and offline (weeks 18–20)

Goal: audio mode works like a podcast app in the car, including when the connection drops.

## Tasks

- [x] **CarPlay scene** (`App/iOS/Sources/CarPlay/`):
  - `CPTemplateApplicationScene` with a tab bar of list templates, and the system `CPNowPlayingTemplate` (fed by the M4 Now Playing and remote-command integration).
  - Plays through the app's shared `PlaybackSession` in audio mode (AVPlayer), so the phone and the car show the same session.
  - The CarPlay audio entitlement is applied to simulator builds only. Add it to device builds once Apple grants it.
- [x] **Lists:**
  - **Continue:** videos in progress.
  - **Queue:** in the order added.
  - **Subscriptions:** the feed, using the app's feed options.
  - Each list is capped at 24 items, and downloaded items are marked.
  - `CarPlayContent` builds the lists as plain values, so they're unit-tested without CarPlay (`SpectoTests`).
- [x] **Chapters as a CarPlay list:** Now Playing's "Up Next" button opens the chapters. Picking one seeks and returns.
- [x] **Queue** (`QueueStore`):
  - Added from the feed's context menu or the Watch screen's queue button.
  - When a video ends, the next queued one plays in the same mode, and the finished one leaves the queue.
- [x] **Background download of queued audio** (`OfflineAudio`, behind `OFFLINE_DOWNLOADS`):
  - **Format:** AAC/MP4 audio from Piped or Invidious, picked by `FormatSelector` for AVPlayer. Downloads use a background `URLSession`; files go to Application Support, excluded from backups.
  - **Playback:** audio mode plays the local file first, and video falls back to it when the network fails.
  - **YT Zero:** its watch page has no separate audio streams, so with only YT Zero configured nothing is downloaded.
  - **Build flag:** `OFFLINE_DOWNLOADS` is set in Debug only. App Store and TestFlight builds never contain downloading (guideline 5.2.3, `docs/distribution.md`).
- [x] **Download management:**
  - **Settings → Offline listening:** storage limit (500 MB–5 GB), current usage, and Delete All.
  - **Eviction:** watched items go first, then items no longer queued, then the least recently played.
  - **Removal:** removing a download cancels it if still in flight, and a late callback can't bring it back (`OfflineAudioTests`).
- [x] **Resume position between car and phone:** they share one database on one device, so this needs no sync. Sync with tvOS ships with M7's CloudKit sync.
- [x] **SponsorBlock in audio mode:** skipping runs in `PlaybackSession` on every engine's position events. `skipsSponsorSegmentsInAudioMode` covers the AVPlayer path, and downloaded audio loads segments too.

## Fixed along the way

- **iPhone tab bar:** subscribed channels showed up as tabs in the iPhone tab bar (`.defaultVisibility(.hidden, for: .tabBar)` didn't hide them). Channel tabs now exist only at regular width, and an open channel moves into the Subscriptions stack when the width turns compact.
- **Copy:** "1 channels" now inflects.

## Verification

- **Unit tests:** Library 27 (queue, downloads, eviction, offline delegate), Playback 41 (audio-mode skip), SpectoTests 3 (CarPlay lists).
- **UI test** `ListeningUITests` against a real Piped instance: queue from Watch, then the queued audio lands on disk and shows in Settings. On disk the file was a 2.4 MB AAC file of 148.7 s, matching the 2:29 video.
- **Manual (owner), CarPlay:**
  1. In the iOS Simulator choose I/O → External Displays → CarPlay.
  2. Check the three tabs, play from each, and use Now Playing controls and the chapters list.
  3. On a device this needs the granted entitlement.
- **Manual (owner), a real drive:**
  1. Queue a few videos at home and let them download.
  2. Drive with poor or no coverage: queued items play from disk, auto-advance works, and positions persist.

**Done when:** a full drive works with spotty or no connectivity, and the CarPlay entitlement is granted (owner action).
